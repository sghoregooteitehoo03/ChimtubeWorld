# 수동 스모크 체크리스트

자동 테스트가 다루지 않는 실제 앱·외부 연동·업데이트 호환성은 이 목록으로 확인한다. 기준 태그(`baseline/v1.4.5-vc10`) 빌드에서 "기준선" 열을 채우고 릴리스 후보에서 "릴리스 후보" 열을 채운다. 기준선 실패는 그대로 기록해 회귀와 구분하며, [의도된 동작 변경](baseline.md#마이그레이션-완료)은 최종 정책대로 확인한다.

기록 방법: ✅ 정상 / ❌ 이상 / ➖ 해당 없음. 두 결과 열은 비어 있다(아직 실행하지 않음).

## 0. 사전 준비

- [ ] 기준 빌드를 설치하고 북마크 2개 이상, 카페 글 읽음 기록 2개 이상을 만든다 (덮어 설치 테스트용).
- [ ] YouTube 앱, Twitch 앱, 네이버 웹툰 앱이 설치된 기기와 설치되지 않은 기기(또는 앱 비활성화)를 각각 준비한다.
- [ ] 라이트/다크 모드를 모두 확인할 수 있게 한다.
